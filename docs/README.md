## Agent Categories

The agents are organized into categories:

```
agents/
├── github/          # Git and GitHub workflow agents (Blue)
├── documentation/   # Documentation generation agents (Yellow)
├── code/            # Code analysis and maintenance agents (Red)
├── testing/         # Testing and debugging agents (Green)
└── infrastructure/  # dotClaude management agents (Pink)
```
